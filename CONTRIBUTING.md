# Contributing to Mr. Donald Food Delivery

Thank you for your interest in contributing to Mr. Donald Food Delivery!

This project is a responsive food delivery website built with HTML, CSS, and JavaScript. Contributions that improve functionality, accessibility, responsiveness, code quality, and user experience are welcome.

## How to Contribute

1. Browse the open Issues and choose a task you would like to work on.
2. Comment on the Issue to let the maintainer know you are interested.
3. Fork the repository to your GitHub account.
4. Clone your fork to your local machine.
5. Create a new branch for your changes.
6. Implement your changes and test them.
7. Push your branch to your fork.
8. Open a Pull Request describing your changes and linking the related Issue.

## Development Guidelines

- Use the existing HTML, CSS, and vanilla JavaScript structure.
- Keep changes focused on the selected Issue.
- Follow the existing naming conventions and coding style.
- Make sure the website works on desktop, tablet, and mobile screens.
- Test existing features to avoid introducing regressions.
- Avoid adding unnecessary dependencies.
- Do not include passwords, API keys, or other sensitive information in your commits.
- Do not introduce unrelated changes without discussing them first.

## Pull Request Guidelines

Every Pull Request should:

- Clearly describe the problem and the proposed solution.
- Reference the related Issue using `Closes #ISSUE_NUMBER` when appropriate.
- Include screenshots for relevant UI changes.
- Explain how the changes were tested.
- Keep the changes as small and focused as reasonably possible.

## Questions and Suggestions

If you have an idea for a new feature or find a bug, please open an Issue before starting significant work. This helps avoid duplicated effort and keeps the project organized.

Thank you for helping improve Mr. Donald Food Delivery!
