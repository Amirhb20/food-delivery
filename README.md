# Food Delivery Website — Mr. Donald

A responsive front-end website for a fast-food brand where users can explore menu items, browse food and drink categories, and interact with basic ordering controls. The project is built with **HTML, CSS, and vanilla JavaScript**.

## Overview

The website presents a single-page food delivery homepage and a separate authentication page. Its design focuses on a clear menu layout, responsive navigation, and interactive elements that make the browsing experience more engaging.

## Features

- **Responsive layout** for desktop, tablet, and mobile screens.
- **Homepage sections:** Home, Menu, Sale Off, News, Contact, and Footer.
- **Mobile navigation:** toggle the hamburger menu open and closed.
- **Menu category filtering:** filter menu cards by the selected category, including the all-items option.
- **Quantity controls:** increase or decrease an item quantity; the quantity cannot go below zero.
- **Scroll progress indicator:** a top bar updates as the user scrolls through the page.
- **Smooth section navigation:** header links scroll smoothly to their corresponding sections.
- **Custom text selection styling** to match the site's visual theme.
- **Authentication page UI:** separate login and sign-up interface with JavaScript interactions.

> **Note:** This is a front-end project. Real user authentication, database storage, order submission, and payment processing require a backend or third-party service and are not implied by the interface alone.

## Getting Started

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code for local development.
4. Open `auth.html` to view the login and sign-up page.

The current static front-end version does not require a build step or package installation.
